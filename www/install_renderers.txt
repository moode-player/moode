OVERVIEW

The "Audio Renderers" are 3rd party playback applications that are separate from
the core playback application in Moode; MPD (Music Player Daemon).

AIRPLAY, SPOTIFY CONNECT AND QOBUZ CONNECT

AirPlay, Spotify Connect and Qobuz Connect renderers are not included in Moode
but they can be built/installed via the INSTALL button in Renderer Config.

INSTALLATION PROCESS

Clicking the INSTALL button initiates a process that first checks the Home
Directory for a Debian package of the correct version and if present performs
a direct install. If the package is not present the renderer sources are
downloaded from their GitHub repository and built (compiled) into a Debian
package that is then installed.

The build process can be lengthy. The amount of time required depends on the
overall speed of the Raspberry Pi including CPU, RAM, and boot media, and the
speed of the network which is used to download the renderer sources and build
scripts from GitHub.

BUILD TIMES

The table below reflects approximate times to build each of renderer plugins on
the latest moode image which includes Git and Rust toolchains pre-installed.

  Plugin    Pi-5 4GB   Pi-4 2GB   Pi-4 1GB   Pi-3B+ 1GB
+---------+----------+----------+----------+------------+
| AirPlay | 3 mins   | 5 mins   | 5 mins   | 8 mins     |
+---------+----------+----------+----------+------------+
| Spotify | 5 mins   | 15 mins  | 25 mins  | 45 mins    |
+---------+----------+----------+----------+------------+
| Qobuz   | 5 mins   | 15 mins  | 25 mins  | 45 mins    |
+---------+----------+----------+----------+------------+

VIEWING THE INSTALLATION LOGS

The summary log is named "/var/log/moode_plugin.log" and can be viewed by
clicking the REFRESH button in the WebUI during installation or in an SSH
terminal by the command "cat /var/log/moode_plugin.log"

The full logs are in the Home Directory and are named "install_airplay.log",
"install_spotify.log" and "install_qobuz.log". They can be viewed in an SSH
terminal by the commands below. The command "tail -f" is used to view the log
as its being written.

Examples:
cat install_airplay.log
tail -f install_airplay.log

INSTALLING ON MULTIPLE SYSTEMS

The Debian packages "filename.deb" are saved to the Home Directory. The System
Backup/Restore feature can be used to backup up and then restore the .deb files
to the Home Directory of another system and then installed directly via the
INSTALL button in Renderer Config.

Manual direct installation can also be performed by using the command below.
sudo moodeutl --installpkg [airplay | spotify-connect | qobuz-connect]
