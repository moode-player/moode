MQTT

Settings
Broker
Address of the MQTT broker.
Usually 1883, or 8883 with TLS.
Leave empty if the broker accepts anonymous connections.
Password of the MQTT user.
Encrypt the connection to the broker. The broker's certificate must come from a public authority such as Let's Encrypt; a self-signed certificate is refused.
Only needed with TLS when Host is an IP address: the domain name the broker's certificate was issued for. Leave empty otherwise.
Player
Identifies this player in the MQTT topics and in the home automation system. Each player on the same broker needs its own. Set from the host name on first start.
Note: Changing it later adds a second device.
Name of the device shown in the home automation system.
Advanced
Topics are published under prefix/instance. Default is "moode".
Where the home automation system looks for new devices (MQTT discovery). Default is "homeassistant".
How often, in seconds, the display and audio output are checked. Playback changes are published at once regardless. Default is 1.0.
Seconds the audio output must stay closed before "Audio active" turns off. MPD closes it between tracks, so keep a few seconds. Default is 5.0.
Step used by the volume up and down commands. Default is 5.
